# 屁岱中断、插话与结果卡

## DeepSeek 对话

依据 [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)：请求带 tools 时，已完成轮次的 reasoning_content 需完整回传，不能裁短已完成的思考记录。

当前流被用户停止或网络打断时，只把已经收到的正文作为普通 assistant 消息保存，并追加 `[用户打断]` 或 `[网络中断]`。尚未完成的这一段思考只留在本地界面，不当作完整 reasoning_content 回传。这是客户端对不完整流的处理方式，官方文档未承诺续接半段思考。

工具轮中已经完成的 tool 结果保留；正在执行的调用标记 execution: unknown，尚未启动的标记 not_started。每条已提交的 tool_call 都配齐对应 tool 消息。取消不能撤销已在远端发生的操作，后续回答应按真实结果或未知状态处理。

用户在回答途中发送新消息，会先取消当前轮；清理和落盘完成后启动下一轮。输入框为空时操作钮停止生成，有草稿时显示发送插话，同时保留独立停止钮。

保留已有历史前缀有利于前缀缓存复用，但不保证被截断的响应曾被服务端缓存。

## 结果卡

查询只取数，返回本轮 result_id 和原始条目编号。模型看到结果后，用 present_result 展示卡片或页面入口；display 在此时筛选字段、条目和排序。无需展示时直接回答。同一结果重复展示会替换旧卡，旧历史中的 show 参数继续兼容。

成绩支持条目、课程、数值分数范围、排序、数量，以及全部查询／所选课程／不显示三种汇总口径。GPA 在本地从真实课程计算，limit 只控制可见条数。

空教室支持 slots（课表空闲条）、status（实时快照）与 both。节次筛选要求所选各节全部空闲，可指定连续空闲节数。课表空闲标作“无课”，不会冒充“此刻无人”；没有实时数据的日期或校区明确回退至课表。

CDN 失败后取数层自动直连教务，最多同时查询两栋楼。card_display 回报实际展示内容；实时状态只代表此刻。sections 表示指定各节全部空闲，min_free_sections 表示全天某处连续空闲。

通知结果与通知页“屁岱精选”复用 NoticePickItem：原标题、来源、日期、原文入口来自查询，推荐理由与重要程度通过 annotations 按原始编号添加。支持选条目、日期范围、来源、字段、数量和排序。

其它卡片按内容提供课程、日期、状态、字段、流水方向、文件／目录、平面图／区域汇总／预约、座位高亮、地图地点／路线等选项。编号和高亮对象只接受快照中真实存在的条目；配置随卡片保存，旧记录使用默认布局。
