# 小岱（AI 助手）

## 中断与插话

依据 [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)：请求带 tools 时，已完成轮次的 `reasoning_content` 需完整回传，不能裁短。

- 用户停止或网络中断时，只把已收到的正文存成普通 assistant 消息，并追加 `[用户打断]` 或 `[网络中断]`。未完成的那段思考只留在本地界面，不当作完整 `reasoning_content` 回传（官方未承诺续接半段思考）。
- 工具轮中已完成的 tool 结果保留；正在执行的调用标 `execution: unknown`，未启动的标 `not_started`。每条已提交的 tool_call 都配齐 tool 消息。取消撤不回远端已发生的操作，后续回答按真实结果或未知状态处理。
- 回答途中发新消息会先取消当前轮，清理落盘后再启动下一轮。输入框为空时操作钮是停止，有草稿时是发送插话，另留独立停止钮。
- 保留历史前缀有利于前缀缓存命中，但不保证被截断的响应曾被缓存。

## 结果卡

查询只取数，返回本轮 `result_id` 和原始条目编号；模型看过结果后用 `present_result` 展示卡片或页面入口，`display` 在此时筛选字段、条目和排序。无需展示时直接回答。同一结果重复展示会替换旧卡，旧历史里的 `show` 参数继续兼容。

- **成绩**：条目、课程、分数范围、排序、数量；汇总口径分全部查询 / 所选课程 / 不显示。GPA 在本地按真实课程计算，`limit` 只控制可见条数。
- **空教室**：`slots`（课表空闲）、`status`（实时快照）、`both`。`sections` 要求所选各节全部空闲，`min_free_sections` 表示全天某处连续空闲。课表空闲标作「无课」，不冒充「此刻无人」；没有实时数据的日期或校区明确回退到课表。CDN 失败后自动直连教务，最多同时查两栋楼。
- **通知**：与通知页「小岱精选」共用 `NoticePickItem`。标题、来源、日期、原文入口来自查询，推荐理由与重要程度经 `annotations` 按原始编号添加。
- **其他卡片**按内容提供课程、日期、状态、字段、流水方向、文件 / 目录、平面图 / 预约、座位高亮、地图地点 / 路线等选项。编号和高亮对象只接受快照中真实存在的条目；配置随卡片保存，旧记录用默认布局。

## 读文档

Android 的 `get_lms_activity`（带 `file`）和 `read_zyxf_file` 共用 `AgentDocReader`。

### PDF

用系统 `PdfRenderer`（Android 15 起能取文字和检索；更低版本每页都当无文字页，走 OCR 或转图，`search` 不可用）。

| `mode` | 行为 |
|---|---|
| `info` | 页数 + 每页首行当目录（前 150 页）；无文字页合并成区间。系统接口不提供书签 |
| `search` + `query` | 逐页 `searchText`，列出命中页、处数和片段（前 30 页）；扫描页检索不到 |
| `text` | 按页取文字，每次最多 20 页、约 12000 字；过长返回 `text_offset` 续读位置 |
| `images` | 只渲染所选页，每次最多 4 页 |
| `auto`（默认） | 取文字；空文字页有 Key 时逐页 OCR（每次最多 8 页），失败退回页面图；无 Key 时转图 |

`pages` 支持 `5`、`1,3,7-8`，默认前 2 页；越界、倒序或超量直接报错，不静默改页。LMS 附件优先按 ID 或完整文件名匹配，多项匹配时返回候选。

### OCR

`DeepSeekOcr` 调 `POST /v1/tools/ocr`（`text_recognition`），Key 与联网搜索共用（`AgentConfig.webSearchKey`），搜索关闭时也不 OCR。

- 扫描页按单页 JPEG 送，不送整份 PDF：省钱，也绕开服务端整份解析随机丢页的问题。
- 服务端偶发整页返回空串，空页最多重试两次。
- 结果按「文件内容 + 页码」缓存（进程内 64 条），翻页续读不重复计费。
- 老式 `doc` / `ppt` 本机解析不了，整份送 OCR；无 Key 时提示用户。

### 其他格式

`docx` / `pptx` / `xlsx` 本机解 zip 取正文，图片直接交给模型，纯文本按 6000 字分段。附件字节按账号缓存 10 分钟，最多 4 份、24 MiB，失败不缓存。

## MCP

设置里填远程 MCP 服务的 `https://…/mcp` 地址和可选 Bearer 令牌，「测试连接」通过后启用。令牌按校园账号存入安全存储。Android 上的 localhost 指手机自身。

- 每次调用都展示服务地址、工具和完整参数，用户允许后才发送。拒绝、停止生成或切换会话不会继续等待中的调用；已发出的写入撤不回，断线或会话过期不自动重试写入。
- 支持 Streamable HTTP（JSON / SSE）、协议 2025-06-18 / 2025-03-26 协商、会话标识、工具分页与调用。只允许 HTTPS（回环地址可用 HTTP），不跟随重定向发送凭据。
- 不支持旧版独立 SSE 端点、stdio、OAuth 交互、resources / prompts / sampling，需要时先接兼容的远程桥接。应用不预置任何第三方凭据。

协议参考：<https://modelcontextprotocol.io/specification/2025-06-18/basic/transports>
