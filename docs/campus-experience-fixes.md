# 校园功能修正

基于 dev `4cfe35bc`。界面文案按“简洁、必要、冷静，适当亲和”调整。

## 功能

| 范围 | 改动 |
| --- | --- |
| 图书馆 | 全屏座位图移到页面层，旋转和网格回收不再销毁窗口；选座与热力状态共用。 |
| 学辅搜索 | 文件夹与独立文件分区，文件保留来源路径，避免误认从属关系。 |
| 通知公告 | 来源直接多选，分类侧栏、跨分类搜索和选中态统一在面板内；确认后刷新，未确认的修改可直接取消。去掉单源／合并模式切换和重复来源文字。搜索短暂失败重试一次，未查全单独说明。 |
| 校园卡 | 全年流水按服务端总数取全；最多三路并发。旧版不完整缓存重新拉取，不再把前十二页当全年数据。 |
| 干饭报告 | 增加消费指标、时段分布和常去商户排行，保留本地计算与导出。消费按“笔”展示。 |
| 成绩单 | 展示学校表单提供的全部可用类型，中文、英文等选择贯穿整个申请流程。 |
| 屁岱登录 | 用户对话允许重新认证和短信验证；失败、取消均结束工具加载。自动卡片与后台查询保持静默。 |
| 屁岱网络 | 未展示回复前，连接失败可短暂等待并重试；截断的工具片段不会执行。已有可见输出时不重放，明确提示重试。 |
| 屁岱规则 | 功能清单补充 MCP 与设置入口；位置未知时不按学籍校区推断；日程只整理用户确认的安排，建议另列。旧会话升级提示版本。 |
| 屁岱展示 | 朴素模式首页同步生效；精选卡片可折叠并记住状态。 |
| 空闲教室 | 页面直接显示“此刻实况／按节找空闲”。 |
| 首页 | 功能副标题不超过九字；分类改为“教务与课程／资料与自习”，课程作业归前者、教材与学习空间归后者。 |
| 思源卡片 | 按当前学期选课，不把最新历史学期当本学期；未查全、未返回本学期课程不解释为没有课程或作业。 |
| 日程 | 自建日程可选颜色；无课提示只描述已有数据，不预设后几天有课。 |
| 场馆 | 系统返回与页内返回共用层级；支付改用业务站 8080 端口下的 `/web/pay/`，浏览器略过认证中间页。 |
| 电费 | 移除路由、界面、登录、接口、后台刷新和相关服务端实现。历史校园卡流水仍正常展示。 |
| 预览更新 | 按发布时间选预览版本，不依赖 GitHub 返回顺序；支持同版本号稳定版转更新的预览版，避免跨版本倒退。 |
| 教材 | ISBN 未匹配时继续按书名匹配，结果有歧义不自动打开。空白处补充简短说明，保留原有全文库栏目。 |
| 文案 | 缩短成绩单、考勤、反馈、付款码、匹配、阅读器及网页版提示；移除面向用户的接口、协议和实现过程说明。 |

## 地图

更新 OpenStreetMap 数据，补上 multipolygon 建筑解析和中文名称优先级。原有地点保留，新增十六处：

- 兴庆：仲英楼、化学楼、外国语学院、文治书院西十八／十九／二十舍、焊接楼、电气绝缘楼、研究生宿舍、篮球场、锅炉房。
- 雁塔：基础医学实验教学中心。
- 创新港：力行楼、敏行楼、泓理楼、躬行楼。

坐标与轮廓来自 OpenStreetMap，生成方式见 `tools/gen-campus-map.py`；未凭空补坐标。曲江数据一并更新。

## 验证

回归覆盖全年分页、英文成绩单类型、预览版本顺序、截断流与重连、学期边界、浏览器认证跳转及通知多来源查询。执行 Android 单元测试、共享模块 JVM 测试、桌面与服务端测试、Web 浏览器测试和跨端编译。

`./gradlew :desktop:renderCampusExperience` 可生成干饭报告、通知明暗主题、多选及确认后的离屏预览，数据均为虚构。输出位于 `desktop/build/campus-experience-preview/`。

学校真实账号的成绩单签发、场馆预约与扣款未执行。支付地址验证止于新站点的认证入口，最终支付仍需真实订单验证；流式连接中断不支持从服务器断点续传。

## 后续调整

- 全屏选座改为左图、右侧操作栏，预约按钮固定在右下；选座时地图尺寸不变。
- 删除首页主题选项、图标布局、专属头卡、插画、配色与相关设置工具，只保留新版首页。
- 空闲教室删除右上角数据源菜单，在“按节找空闲”中选择 CDN 或直查，并记住选择。
- 首页只展示及格的体测成绩，其他结果保留查询入口；502 提示学校服务暂不可用，保留重试。

另已定位屁岱简报的详情问题：正文已保存，但消息路由直接打开屁岱页，没有携带正文。这一项本次仅诊断，未修改。
