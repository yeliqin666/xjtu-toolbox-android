# 基础存储回归检查

本分支以 69e6a68fce7621d9d310d80e0fa80abbf1914e1f 为原始缺陷版本，合并 S1/S2 的独立修复分支。

- PR Gate：保留原有跨平台验证，补充 `:app:testDebugUnitTest`。
- Storage regression checks：Linux 上对修复版和固定的原始版本运行相同的 7 条回归断言；Windows 上验证 model/data 的文件存储及凭据保护测试。
- 原始版本必须产生预定的断言失败，修复版必须通过。编译失败、依赖下载失败、测试未运行、测试跳过或其他原因失败均不算复现。
- 基线只复制测试源码，保持原始生产代码与构建配置；报告按版本和模块保存。基线固定，不随 main 漂移。
- 检查涵盖进程内多实例、临时文件清理、存储工厂覆盖、错误的根目录缓存、旧句柄复活、损坏文件与写入失败。它不证明跨进程互斥、断电耐久性或 Android 真机表现；这些需要独立验证。
- 单独的并发压力测试在 PR Gate 中执行。S1 的互斥复现使用反射取得真实锁来控制交错顺序；若锁结构变更导致反射失败，CI 应失败并要求更新测试，不能把它认成复现成功。

运行：在 fork 的 Actions 页面启用工作流后，由本仓库的 PR 自动触发。工作流在默认分支可用后也可手动运行。不需要签名、发版、学校账号或外部服务密钥。
