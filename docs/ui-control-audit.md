# 控件样式检查（2026-10-23）

本轮从 Android 页面与共享 Compose 组件检查入口、展开、分页、重试和状态控件。已结合设备截图确认资料预览问题；其余清单是代码检查发现的视觉优化候选，不能替代逐屏真机验收。普通的标准弹窗按钮不算问题。

## 本轮已调整

| 位置 | 调整 |
| --- | --- |
| 资料预览弹窗 | 下载移到底部并显示持久结果；删除弹窗内多余关闭叉，拖动区与文件头统一底色。 |
| 学辅排序 | 规则、方向、展开箭头收进同一面板，选项放在面板内。 |
| 社区楼中楼 | 展开、分页、加载中和失败重试共用紧凑的内嵌操作行，和回复正文缩进对齐。 |
| 屁岱过程卡 | 固定宽度与状态槽，避免摘要增长时横向伸缩；流式思考先按普通文本显示。 |
| 我的学籍联系人 | 辅导员、班主任行从至少 48dp 收到 32dp，并减少号码上下留白。 |
| 首页 Hero | 长按设置；纯色或液体；删除恢复默认按钮。 |
