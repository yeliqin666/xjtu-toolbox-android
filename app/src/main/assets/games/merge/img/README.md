# 校徽素材占位说明

当前目录为空：游戏运行时会依次尝试加载 `game_c9_<key>.webp`、`game_c9_<key>.png`，
都找不到就自动用 `index.js` 里的 `drawPlaceholder()` 画一个纯色圆 + 校名文字当占位图，
所以没有真实素材也能正常玩。

## 替换方法

把校徽图放进本目录，文件名和顺序必须与下表一致（对应 `index.js` 里的 `LEVELS`
数组，从小到大）：

| 文件名（.webp 或 .png 皆可） | 高校 |
| --- | --- |
| `game_c9_hit` | 哈工大 |
| `game_c9_ustc` | 中科大 |
| `game_c9_nju` | 南大 |
| `game_c9_zju` | 浙大 |
| `game_c9_fudan` | 复旦 |
| `game_c9_sjtu` | 上交 |
| `game_c9_pku` | 北大 |
| `game_c9_thu` | 清华 |
| `game_c9_xjtu` | 西交大 |

要求：正方形、透明底、512x512（`.webp` 优先于同名 `.png`）。放进来之后不需要改任何
代码，游戏会自动优先加载真实图片；`TEXTURE_SIZE` 常量已按 512 配置，尺寸不同也不会
变形（按半径自适应缩放），但清晰度以 512 为准。

> 合成链顺序（哈工大→中科大→南大→浙大→复旦→上交→北大→清华→西交大）是需求方给的，
> 待仓库主最终核对是否符合预期的梗/难度顺序；如需调整，改 `index.js` 里的 `LEVELS`
> 数组顺序即可，其余逻辑不用动。
